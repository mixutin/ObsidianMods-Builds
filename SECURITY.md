# Security

ObsidianMods-Builds is a distribution-only repository.

- Mod implementation source must not be committed here.
- Release assets are versioned and referenced by SHA-256 from the public Obsidian Mods catalog.
- Catalog installs are accepted only from this repository's GitHub Release download path.
- If a release asset or checksum is suspected to be compromised, mark the catalog entry blocked before publishing a replacement build.

Report security issues privately to the repository owner rather than opening an issue with exploit details.
